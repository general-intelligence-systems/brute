# 08-checkpoints

Checkpoints — durable execution for the tool loop.

## Run

```
nix run ./examples/08-checkpoints
nix run ./examples 08-checkpoints        # via the dispatcher from the repo root
```

Ollama defaults to localhost:11434 (see docker-compose.yml at the repo root); override with BRUTE_PROVIDER / BRUTE_MODEL and the matching *_API_KEY.
