# Examples

Three categories:

- **[agents](agents/)** — single agents: *prompt + tools + skills*. Ports of
  [dexter](https://github.com/virattt/dexter),
  [google-calendar-agent](https://github.com/inference-gateway/google-calendar-agent),
  [grafana-agent](https://github.com/inference-gateway/grafana-agent),
  [browser-agent](https://github.com/inference-gateway/browser-agent), and the
  [OpenFang](https://github.com/RightNow-AI/openfang) agent catalog, plus the
  original numbered walkthroughs.
- **[teams](teams/)** — agents wired together (a lead agent delegating to
  `Brute::Tools::SubAgent` specialists). Ports of
  [paperclipai/companies](https://github.com/paperclipai/companies).
- **[workflows](workflows/)** — nothing here yet.
